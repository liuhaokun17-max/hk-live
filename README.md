# Hong Kong Live

A static dashboard for live Hong Kong weather, MTR transport and air-quality readings.
Live site: https://liuhaokun17-max.github.io/hk-live/
Data sources: Hong Kong Observatory, Government of the HKSAR / DATA.GOV.HK, and MTR.
Run locally with `python -m http.server 5500`, then open `http://localhost:5500`.
Run the formatting tests with `node --test` (Node.js 20 or newer).
An AI coding agent produced substantial parts of this project; the data logic and failures were reviewed and tested.
